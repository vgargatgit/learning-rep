# Contributing

Before changing a displayed equation or number:

1. update or verify the executable calculation;
2. run `make test`;
3. update the lesson text;
4. update the visual draft or final SVG/HTML rendering;
5. complete `docs/05-image-review-checklist.md`.

Prefer small changes with one pedagogical purpose. Avoid combining visual restyling, mathematical corrections, and lesson restructuring in the same commit.
