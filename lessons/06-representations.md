# Lesson 6 — Internal representations

A hidden layer transforms raw inputs into activations used by later layers. The vector of hidden activations is an **internal representation** of the input.

The representation is not normally specified by a teacher. It emerges because weight updates make hidden activations more useful for reducing the task loss.

For educational illustrations, a hidden unit may be shown as becoming sensitive to a feature such as an edge. This must be presented as an example of an emergent feature, not as a guarantee that every hidden unit has a simple human-readable meaning.
